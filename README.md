## Clone `Galaxies-dev/chatgpt-clone-react-native` exactly

Use the official Git URL and include submodules and tags:

```bash
git clone --recurse-submodules https://github.com/Galaxies-dev/chatgpt-clone-react-native.git
cd chatgpt-clone-react-native
git fetch --tags
git submodule update --init --recursive
```

Optional verification:

```bash
git remote -v
git status
```
